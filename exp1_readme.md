## 📚 Theory: IDLE Execution Modes

### ⚡ Interactive Mode (The Shell)
The **Interactive Mode** is a live command-line interface where code is executed line-by-line. 
* **Key Feature:** Immediate feedback via the `>>>` prompt.
* **Best For:** Quick testing, debugging, and using Python as a calculator.
* **Persistence:** Code is not saved; it exists only for the current session.

### 📝 Script Mode (The Editor)
The **Script Mode** is a text editor used to write complete programs saved as `.py` files.
* **Key Feature:** Allows writing complex, multi-line logic that can be edited and reused.
* **Best For:** Building applications and structured lab assignments.
* **Persistence:** Code is saved permanently on the hard drive.
